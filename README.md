# Karen Tatiana Martínez — Personal Portfolio

A personal portfolio designed as a **library**: an open book on top of a stack of books. The open book shows who I am, my selected work and my languages. Each book in the stack has a small label (About me, Hackathons, Projects, Skills & tools, Contact); tap one and it opens as a book with that section. Built by hand with vanilla HTML, CSS and JavaScript.

🌐 **Live Site:** [katamar-lang.github.io/PORTAFOLIO](https://katamar-lang.github.io/PORTAFOLIO/)

## ✨ Features

- **Library home:** an open book and five closed books, drawn with CSS only (no images)
- **Reader:** each book opens as a page spread with a dark spine on the left and the other books standing on the right to switch sections
- **Shareable links:** `#about`, `#hackathons`, `#projects`, `#skills`, `#contact` open that book directly
- **Accessible:** real buttons, keyboard and Escape to close, focus returns to the book, reduced-motion support, 44 px touch targets
- **Responsive:** checked at 1280, 390 and 320 px; on phones the books become tabs at the bottom
- **Social preview** image (Open Graph) for LinkedIn, X and WhatsApp
