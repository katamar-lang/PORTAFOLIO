# Karen Tatiana Martínez — Personal Portfolio

An editorial one-page portfolio: an ivory page on a soft green-grey background, with layered "pages", soft shadows and a serif + sans type pair. Built by hand with HTML and CSS (no frameworks, no JavaScript needed).

🌐 **Live Site:** [katamar-lang.github.io/PORTAFOLIO](https://katamar-lang.github.io/PORTAFOLIO/)

## ✨ Features

- **Cover:** name, specialty, a short introduction, two actions (View projects, Contact) and two project plates as a secondary visual
- **Projects as editorial pieces:** image, title, summary, my contribution, technologies and links
- **Depth with CSS only:** offset page layers and soft shadows; all text is real HTML
- **Its own phone layout:** single column, comfortable margins, full-width actions, fewer decorations
- **Accessible:** skip link, 44 px+ targets, readable sizes, visible focus, reduced-motion support
- **Social preview** image (Open Graph) for LinkedIn, X and WhatsApp

## 🛠 Technologies

- HTML5 (semantic markup)
- CSS3 (custom properties, grid, flexbox, animations)

- [Junicode](https://open-foundry.com/fonts/junicode) for titles (by Peter S. Baker, SIL Open Font License, see `fonts/OFL.txt`) + DM Sans (Google Fonts)
